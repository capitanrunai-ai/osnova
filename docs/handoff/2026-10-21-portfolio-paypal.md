# Портфоліо D&S та PayPal

Зміни виконано лише локально. Публікація, push і деплой не виконувалися.

- Головні картки: DDS Service → D&S Automotive Repair Solutions → Comfort Lab.
- BALA GROUP збережено в додаткових проєктах головної та загальному каталозі; URL попередніх кейсів збережено.
- D&S використовує наявний шаблон `/[lang]/cases/ds-repair-solutions`: локалізований опис, обсяг реалізації, 16 категорій, 138 послуг, приблизно 48 годин розробки та 45 днів підтримки за чинними умовами.
- Тексти описують технічну SEO-підготовку без обіцянок чи заяв про позиції та зростання трафіку.
- PayPal додано четвертим способом на `/[lang]/payment`, у короткому переліку, лічильнику та метаописі. Перші три способи й реквізити не змінено; платіжних форм, API та Checkout немає.
- Оновлено українську, англійську, німецьку та російську версії. Наявні генератори canonical, hreflang, prerender і sitemap використовуються без нової SEO-архітектури.

## Джерела

Скриншоти зроблено з [D&S](https://dsrepairsolutions.com/), окреме прев’ю каталогу — з [Services](https://dsrepairsolutions.com/services/). Також переглянуто About, сторінки категорій і окремої послуги Engine Oil Change. Форми не надсилалися. Приватні деталі реалізації, строк і підтримка наведені за інформацією власника проєкту.

Відтворення скриншотів: `node scripts/capture-ds-repair.mjs`. Матеріали перевірки зберігаються локально в `.visual-audit/` (ігноруються Git).

Локальний SVG-логотип PayPal: [Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/b/b5/PayPal.svg). Під час перегляду сайту логотип завантажується з власного `/assets/paypal.svg`.

## Локальний перегляд

У PowerShell із каталогу проєкту:

```powershell
npm.cmd run dev -- --host 127.0.0.1
```

- Головна: `http://127.0.0.1:5173/uk/#cases`
- D&S: `http://127.0.0.1:5173/uk/cases/ds-repair-solutions`
- Оплата: `http://127.0.0.1:5173/uk/payment`
- Мови: `uk`, `en`, `de`, `ru` у першій частині URL.

## Перевірки

Збірка з канонічною адресою (змінна діє лише в поточному процесі PowerShell; нічого не публікує):

```powershell
$env:SITE_URL = 'https://osnovaai.com'
npm.cmd run build
npm.cmd run verify:seo
node scripts/portfolio-audit.mjs
npm.cmd run audit:payment
npm.cmd run audit:case-services
```

Перевірки зібраного `dist` слід запускати після завершення збірки.

Результати: збірка успішна; SEO — 84 індексовані сторінки та 4 сторінки 404; портфоліо — 80 перевірок сторінок і розмірів; оплата — 4 мови × 5 розмірів; аудит послуг і кейсів — 232 перевірки та 1468 внутрішніх посилань. Помилок консолі, зламаних зображень і горизонтального переповнення не виявлено. Усі 9 зовнішніх адрес проєктів, включно з посиланням на попередній сайт Comfort Home, відповіли HTTP 200. Порівняння з початковим Git-станом підтвердило, що перші три способи оплати не змінено в жодній мові.
